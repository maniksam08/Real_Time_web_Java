# 💬 Real-Time Web Chat — Java (Spring)

A real-time chat application built to practice backend development with the **Java Spring ecosystem**. Real-time message delivery is handled via **WebSockets**, with a deliberately minimal HTML/CSS frontend — the focus of this project is the backend service, not UI polish.

> Built as a learning project to get hands-on with Spring's WebSocket support and backend service design in Java.

---

## ✨ Features

- 🔄 **Real-time messaging** — instant message delivery over WebSockets
- 🧱 **Backend-first design** — core focus on Spring backend architecture, connection handling, and message routing
- 🖥️ Minimal HTML/CSS frontend — just enough UI to demonstrate and test the backend functionality

---

## 🛠️ Tech Stack

**Backend:** Java, Spring Framework, WebSockets
**Frontend:** HTML, CSS

---

## ⚙️ Getting Started

### Prerequisites
- JDK installed (Java 17+ recommended)
- Maven (or Gradle, depending on the build setup)

### Installation

```bash
git clone https://github.com/maniksam08/Real_Time_web_Java.git
cd Real_Time_web_Java
```

### Run

```bash
# If using Maven
mvn spring-boot:run
```

Then open `http://localhost:8080/chat` in your browser to try the chat.
